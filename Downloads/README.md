# Versioned packages

Current preview: v0.3.1. The preview ZIP contains the loadable UXP panel, Node client, English/Hungarian instructions and MIT license. The source ZIP also includes tests, the package builder and Codex development instructions. Choose a ZIP in this directory and extract it to a writable local folder; follow the included installation guide.

This preview has automated protocol and mock tests, but live panel execution and book-builder fidelity remain unverified. It is a UXP development-load package, not a signed CCX installer. Earlier v0.3.0 files remain available for comparison/rollback. No executable installer, fonts or user documents are included in these new packages. This directory is the current distribution location; it is not a GitHub Releases page.
