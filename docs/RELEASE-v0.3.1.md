# Codex InDesign Bridge v0.3.1 — preview

Local InDesign UXP file bridge with the experimental restorationBook operation. The base operations are retained. Experimental build/save requires explicit opt-in, and experimental export refuses existing outputs. Client and panel versions must match.

Choose the preview user ZIP for loading the panel, or the source ZIP for development. Extract to a writable local folder and follow the included INSTALL/USAGE guides (English and Hungarian). Adobe UXP Developer Tool and Node 18+ are required. No API key or third-party Node dependencies are needed. This is not a signed CCX installer.

Protocol, simulated queue, attachment/backup and experimental guards are tested. Live v0.3.1 panel loading/execution, automatic builder fidelity and another-machine installation are unverified. The earlier book templates required additional native repairs. Use disposable documents for experimental host checks.

The packages contain source code, guides and the existing MIT license; no user documents, fonts, credentials or session data are included. Checksums accompany both ZIPs. This independent project has no official Adobe/OpenAI endorsement.
